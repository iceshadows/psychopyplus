#  入门指南¶

作为一款应用程序，Wrysyslab Studio 主要包含两个视图：[ *构建器*](https://psychopy.readthedocs.io/en/stable/builder/builder.html)视图和[*编码器*](https://psychopy.readthedocs.io/en/stable/coder/coder.html)视图。它还提供了一个底层 [*API*](https://psychopy.readthedocs.io/en/stable/api/api.html)，可供用户直接调用。

1. ------

   [*构建器* ](https://psychopy.readthedocs.io/en/stable/builder/builder.html)。您可通过其直观的图形用户界面（GUI），轻松从构建器生成多种实验方案。这或许就是您所需完成的全部操作。
   但您始终可以将实验编译成 Python 脚本进行微调，这对经验丰富的程序员而言是快速探索 Wrysyslab Studio 部分库和规范的便捷途径。

   ------

   

2. ------

   [*编码器* ](https://psychopy.readthedocs.io/en/stable/coder/coder.html)。对于熟悉编程的用户，编码器视图提供了一个基础代码编辑器，支持语法高亮、代码折叠等功能。重要的是，它拥有独立的输出窗口和演示菜单。
   演示内容展示了如何执行特定任务或使用特定功能，它们并非完整的实验。
   [*TheCoder 教程*](https://psychopy.readthedocs.io/en/stable/coder/coder.html)应能助您入门，[ *而 API 参考*](https://psychopy.readthedocs.io/en/stable/api/api.html)文档将为您提供详细说明。

构建器和编码器视图是 Wrysyslab Studio 应用程序的两大核心组件。若您在 **Windows 系统上**安装了独立版 Wrysyslab Studio，则应能在"开始"菜单的"程序"列表中找到醒目的 Wrysyslab Studio 链接。 若**在 Mac OS X 系统**安装独立版 **，** 则应用程序位于您放置的位置（！）。在这两个平台上，可通过"视图"菜单打开构建器和编码器视图，默认视图可在首选项中设置。 **在 Linux 系统中，** 可通过命令行启动 Wrysyslab Studio，或创建启动图标（具体方式取决于桌面环境和发行版）。
如果以参数 —-coder（或 -c）或 —-builder（或 -b）启动 Wrysyslab Studio 应用程序，则首选项将被覆盖，并在应用程序启动时创建该视图。

------

对于经验丰富的 Python 程序员，完全可以不打开 Builder 或 Coder 就使用 Wrysyslab Studio。只需安装 Wrysyslab Studio 库及其依赖项，然后用你喜欢的集成开发环境（IDE）代替 Coder 即可。

每次运行 Builder 实验时，Wrysyslab Studio 都会先将其转换为 Python 代码，然后执行该代码。

为更深入理解上述 Builder 程序中“幕后”发生的情况：

- 在构建器中，加载或重新创建您的“hello world”程序。

- 不要直接运行程序，请显式将其转换为 Python 代码：按 F5 键 ，或点击编译图标：

视图将自动切换至编码器，并显示 Python 代码。若您保存并运行此代码，其效果将与直接在构建器中运行完全一致。

##  直接代码编译¶

能够检查构建器生成的代码固然不错，但你也可以直接编写自己的代码。借助编码器和各种库，你可以使用功能齐全的现代编程语言（Python）实现计算机几乎所有可能的功能。

为了丰富多样性，让我们向西班牙语世界问好。Wrysyslab Studio 支持 Unicode（UTF-8）。

若您尚未进入 Coder 界面，请立即切换至该界面。

- 新建代码文档：Ctrl-N/Cmd-N。

- 输入（或复制粘贴）以下内容：

  ```
  from psychopy import visual, core
  
  win = visual.Window()
  msg = visual.TextStim(win, text=u"\u00A1Hola mundo!")
  
  msg.draw()
  win.flip()
  core.wait(1)
  win.close()
  ```

- 保存文件（与在 Builder 中相同的方式）。

-  运行脚本。

请注意，尽管此代码版本比生成器生成的代码简单得多，但屏幕上显示的事件完全相同。（生成器实际上做了更多工作，例如提示输入科目编号。）

- 类似于上述情况，我希望在对话框中添加建议输入项作为辅助功能。例如，当右键点击输入框（如刺激方位输入框）时，应弹出包含数值建议和已知局部变量（如“thisTrial.”）的上下文菜单。

# 构建器概念¶
## 例行程序与流程¶
Wrysyslab Studio 应用程序的构建器视图旨在支持快速开发各类实验，适用于实验心理学与认知神经科学领域的实验设计。

构建器视图包含两个主要面板：左上角用于查看实验的例程 ，窗口下部则用于查看流程 。

实验可以包含任意数量的例程 ，用于描述刺激、指令和反应的时间安排。这些例程以基于轨道的简洁视图呈现，类似于视频编辑软件的界面，允许刺激反复出现和消失，并实现彼此间的重叠。

这些例程的组合和/或重复方式由流程面板控制。所有实验都仅包含一个流程 。该流程采用标准流程图形式，允许例程序列依次执行，并可在单个或多个例程周围插入循环。循环同时控制在重复过程中变化的变量，例如刺激属性。

## 示例1 - 反应时间实验¶
对于一个简单的反应时间实验，可能需要 3 个例程 ：一个用于展示说明并等待按键输入，一个用于控制试验计时，一个在实验结束时向参与者致谢。这些例程可在流程中组合 ， 使说明先呈现，随后进行试验 ，最后执行致谢例程 。同时可插入循环结构，使每个例程针对 6 种刺激强度各重复 4 次。

## 示例 2 - fMRI 区块设计¶
许多功能磁共振成像实验采用区块设计呈现刺激序列。为此，存在多种构建实验的方式：
我们可以创建一个包含多个刺激的单一程序， 按顺序呈现这些刺激，随后设置较长的空白期以形成时段间隔，并用循环结构包裹该程序来控制刺激块。
或者，我们可以创建两组例程 ：一组用于呈现单一刺激（持续 1 秒），另一组用于在较长时间内显示空白屏幕。借助这些例程， 我们可以插入两组循环：一组循环重复执行刺激例程 （使用不同图像），随后执行空白例程 ；另一组循环则包裹整个流程并控制区块切换。

## 斯特鲁普演示¶
本程序演示斯托普效应 [1] 的数字实验。实验呈现一系列用彩色"墨水"书写的彩色单词。受试者需报告每个单词字母的颜色，但当字母拼写的颜色与字母本身颜色不一致（即不协调）时，报告难度会显著增加。
在一致性试验（字母颜色与书面单词颜色相匹配）中，反应时间比不一致性试验更快。

通过这个演示，您需要注意：
如何在.csv 或.xlsx 文件中设置试用列表
如何记录按键操作及反应时间（使用 trialRoutine 中的 resp 组件 ）
如何在循环每次迭代时更改刺激参数。 单词组件的文本和 RGB 值基于 thisTrial（代表试验循环的单次迭代），这些参数已被设置为每次重复时改变（请务必执行此步骤！）。
如何呈现指令：只需设置一个持久的 TextStim，然后在按下按键时强制结束 Routine（但无需存储按键操作）。
[1]	斯特鲁普，J.R.（1935）。《对连续言语反应中干扰现象的研究》。《实验心理学杂志》18: 643-662。

该信息随后通过‘$expInfo[‘ori’]’输入到刺激参数中。

输入参数¶
组件参数的大多数输入框仅接受文本、数值或列表（用方括号括起的值序列）作为输入。
此外，用户可在大多数实验步骤中插入变量和代码，这些内容将在实验开始时或实验过程中按固定间隔进行解释。

要向 Wrysyslab Studio 表明某个值代表变量或 Python 代码而非字面文本，应在该值前添加$符号。 例如，在文本组件的文本字段中输入 "intensity" 会直接呈现该字符串，而输入$intensity 则会触发 Python 在脚本中搜索名为 intensity 的变量。

与循环相关的变量也可通过此方式输入（更多细节请参阅从组件访问循环参数 ）。但该功能同样可用于评估任意 Python 代码。

例如：

随机数(2)
将生成一对随机数

$“yn”[randint(2)]
将随机选择第一个或第二个字符（y 或 n）

globalClock.getTime()
将当前时间（以秒为单位）插入到 globalClock 对象中

$[sin(角度), cos(角度)]
将插入某个角度的正弦和余弦值（例如用于刺激的 x、y 坐标）

变量/代码的评估频率¶
若需通过代码评估刺激参数，还需确定其更新频率。默认情况下，组件参数被设为常量 ——参数将在实验开始时设定，并保持不变直至实验结束。另一种方式是设置为每次重复时改变，此时参数将在每次例程重复开始时重新设定。 最后，许多参数甚至可设置为每帧更新，使其在屏幕刷新时持续变化。
